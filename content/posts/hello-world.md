## 开场

博客搭起来了。

这是一个基于 **Hugo** 和 **hugo-coder** 主题的静态站点，托管在 GitHub Pages 上。
和大多数技术博客一样，它最初的用途是记录学习和思考。

## 为什么写这个站

我平时的笔记散落在多个地方：本地 Markdown、代码注释、聊天记录里的临时结论。
零散的问题在于，**要找回来的时候总找不到**。

搬到公开博客上有两个好处：

1. 写作本身会强制把思路整理清楚——写不明白，通常说明还没想明白。
2. 内容有了稳定的地址，可以被搜索引擎索引，也可以被别人找到。

## 这个站用什么搭的

| 层次 | 选型 | 说明 |
| --- | --- | --- |
| 静态生成 | Hugo | 构建快，产物就是纯静态文件 |
| 主题 | hugo-coder | 极简单列布局，配置集中在 `hugo.toml` |
| 部署 | GitHub Pages | 推代码即发布，零成本 |

架构上没有任何服务端逻辑：所有内容都是仓库里的 Markdown 文件，
提交后由 GitHub Actions 构建成 HTML。这个选择的代价是必须接受它的写作流程，
回报是完全不用担心服务器和数据库会挂。
